  WNBA picks (ContentAuditor + ChromeAuditor — FAIL if missing):
  - Face chip label Consensus Historical Record
  - Value format ONLY: `Unanimous: W-L` or `All but <Model>: W-L` or `Split: W-L-P`
  - FAIL if value has 3/4, Last 7 Days, Strong consensus, or blanket wrong pattern
  - No duplicate H2H Last 10 on face
  WNBA results: season not stuck on July ~67 band; Model Performance /
  Season must say records are graded decisions (not every completed final).

  MLB / NFL / NCAAF / CFL picks Consensus face (compact_consensus_hist_face_issues):
  - FAIL if face still has `Last 7 Days`, `/ no consensus`, or pct clutter
  - Expect compact `Consensus Record: 3/6 Split (0-0)` (pattern + W-L only)

  CFL (when unlocked): H2H Last 10 from real meetings; no empty Books
  spread/total chips; consensus/chart not a thin stub.

  Tennis (shared 1vs1 with UFC — FAIL if missing):
  - Picks not empty when ESPN ATP/WTA has a slate (tennis_picks_slate_issues)
  - Results Cards|Chart are href toggles (pl-view-btn), not setPicksView
  - Cards = UFC/1vs1 template: date-nav, date-sections, Best Performing /
    LN·L7·Season, Consensus table, then result cards (shared card width)
  - Chart stays analytics (no date-section match boards)

  UFC picks: Consensus Historical Record face chip
  (`Unanimous: W-L` / `All but …: W-L`) on each card.

  Golf picks: golf-board.css served; Active chips are golf-chip pills;
  model cells stacked (rank over %); tournament select styled.
